FAQ

Pertanyaan sebelum uang berpindah tangan.

Apakah aplikasi membutuhkan internet?

Tidak untuk penggunaan normal. Versi Lite dirancang offline dan tidak bergantung pada server.

Apakah harus membuat akun atau login?

Tidak. Tidak ada akun, PIN, Firebase, cloud, atau sinkronisasi pada versi Lite.

Data disimpan di mana?

Data utama disimpan secara lokal pada perangkat. Backup dapat dibuat menggunakan fitur Backup & Restore.

Android berapa yang didukung?

Target versi Lite adalah Android 8 sampai Android 17, dengan minimum Android 8 / API 26.

Apakah bisa memakai logo organisasi sendiri?

Ya. Nama organisasi, logo, warna aksen, dan layout dashboard dapat dikustomisasi.

Apakah bisa dipakai untuk kelas?

Bisa. Struktur fiturnya juga cocok untuk administrasi kelas seperti data anggota/siswa, presensi, kas, inventaris, dan kegiatan.
